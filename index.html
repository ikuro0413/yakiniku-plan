01現在地

口コミを一次情報で取った結果、前提が2つひっくり返った。

わびのやは2026年2月11日オープンの新店

Googleクチコミに「2026年2月11日にオープンした焼肉屋さん」との記載。他の口コミも「オープン間もない」「オープンの翌日に伺った」と一致する。

2月開業 → 5月に170万円 → 7月に改装休業。170万円は衰退した店の数字ではなく、開業4か月目の立ち上げ途中の数字。口コミが10〜15件しかないのも半年未満なら当然で、品質の欠陥説より単に認知が積み上がっていないという説明のほうが自然。

Googleマップが休業中なのに「営業中」のまま

ホットペッパーは「改装のため休業中」と正しく出ているのに、Googleマップは営業中（営業終了13:30／再開18:00）と表示されている。客が来て閉まっている状態が今まさに起きている。

  2. 少人数でも注文しやすいセット・盛り合わせがない ← 客単価2,700円の直接の原因
  3. 内装のチープさ（改装で解消に向かっている）
  4. ロースターの加熱が遅い（設備マター）

食べログの表示予算は夜5,000〜5,999円。実際の客単価は2,700円。客が想定の半分しか使っていない。

02コンセプト

口コミに自然発生している言葉を、そのまま看板にする。

靴を脱いで上がる、ご近所の焼肉屋

清澄白河で、靴を脱いで食べる焼肉。

玄関で靴を脱いで個室というか洋室へ通される、だれかの自宅みたいな感覚

店内はとてもアットホームな感じで過ごしやすい空間

この体験は他の焼肉店が模倣できない。 一軒家・個室4室・靴を脱ぐという構造そのものが資産になっている。

「隠れ家」を捨てる

公式サイトは今「清澄白河の隠れ家焼肉」を名乗っているが、これは新店にとって毒。「隠れ家」は知る人ぞ知る状態を肯定する言葉で、認知ゼロを正当化してしまう。実際、口コミの最大の弱みが「入口が目立たない」「看板がなく店舗感がない」。

隠れ家を気取れるのは繁盛してから。代わりに置くのは「ご近所の定番」。月に一度ではなく、週に一度来られる店。

04席の構成

改装で席は増えるが、同時に全部は開けない。

焼肉は2Fの12〜15席に縛られるが、軽食なら30席すべて使える。 焼肉の売上には物理的な天井があり、超える分はロースターを使わない商品で作るしかない。ここから全部が決まる。

フロア席数昼夜開放
1F10席軽食ドリンク＋冷菜・待合第1段階
2F約20席軽食焼肉第1段階
3F約20席軽食予約・個室のみ10月
テラス12席軽食ドリンク＋冷菜第1段階

第1段階は1F・2F・テラスの約42席。 2Fが埋まらないうちに3Fを開ける意味がないし、3Fは200V・照明・換気扇と最も工事が重い。ただしテラスは夏のうちに開ける。工事は終わっているので、開けなければ季節ごと失う。

夜にフロアを開ける基準

席の有無ではなく、調理人の手が要るかどうかで決める。

  • 手が要る＝焼肉・定食 → 2Fのみ
  • 手が要らない＝ドリンク、キムチ・ナムル・サラダ・冷菜（仕込みで完結） → 1F・テラスも可

この線を引いておけば、2Fが埋まったときの受け皿と夏のテラス需要は取れる。

05内装の雰囲気

味気なさの原因はほぼ照明。そして照明は今しか変えられない。

照明の仕様決定は電気工事の発注前に置く。 3F照明は未取付なので器具も配線位置も選び直せるが、工事後は壁と天井を壊す話になる。

1F

玄関と土間の延長。靴を脱ぐ導線がここにある。昼の軽食で使うのでやや明るめ。一人客が座りやすい配置。

最も「家」らしいフロア。障子と和紙の照明。子連れと宴会の主戦場。畳の上にロースターは火気の面で不可なので床仕様の確認が要る。

撮りたくなる場所を1箇所

06看板メニューの設計

値上げは一切しない。頼みやすくするだけで単価が上がる。

品数やセットなどの少人数でも注文しやすいメニューがなく頼みづらかった

表示予算は夜5,000〜5,999円、実単価は2,700円。値付けの問題ではなく、頼みにくいから注文点数が伸びていない。

第1層：集客のフック

原価度外視の厚切り牛タン。 既存の看板をそのまま維持する。口コミで既に認識されており、新しい看板を作るより早い。役割は集客であって利益ではない。

第2層：単価の柱 — 盛り合わせ3段

メニューの最上段に置く。これが客単価を作る本体。

商品内容価格
ひとり盛り1人前¥2,500
ペア盛り2人前¥4,500
わびのや盛り3〜4人前・大皿¥6,800

「わびのや盛り」がファミリーの標準注文になる。「これ1つ頼めば大体OK」という商品を作る。大皿で出して見た目のインパクトを持たせれば、そのまま媒体とSNSの写真になる。

「ひとり盛り」は口コミへの直接の回答であり、同時に一人焼肉という取りにくい層を開ける鍵にもなる。

第3層：利益の柱

ホルモン盛り。 原価率が突出して低く、量で殴っても利益が残る唯一の玉。訴求軸は「あそこの盛り合わせ、ほんとに安いよね」。リピートの理由になる。

昼の軽食（山王苑のランチ資産を流用）

山王苑がランチを止めたことで、開発済みのランチメニュー10種が遊んでいる。写真撮影・価格決定・チラシデザインまで完成しており、焼肉の仕入れをそのまま使って仕込みで完結する。開発ゼロ・撮影ゼロで昼のラインナップが揃う。

08工事・購入備品

漏れると再開後に手戻りするものを、法令まで含めて洗った。

要確認進める前に潰す3点

  1. 2Fの排気ダクトの出口はどこか — 3Fやテラス付近に出ていると新フロアが焼肉臭の中になる
  2. 建物全体の契約電力に余裕があるか — 足りないと受電容量の増設で工期が跳ねる。唯一の工期リスク

A. 電気工事（一括で発注する）
